## 🏗️ โครงสร้าง Partition (The Architecture)
จัดสรรพื้นที่ขนาดรวม 2 TB ของ External SSD ออกเป็น 3 ส่วนหลักตามวัตถุประสงค์การใช้งาน:

| ส่วนที่ | ชื่อพาร์ทิชัน (Label) | ขนาด (Size) | รูปแบบ (Format) | หน้าที่หลักและวัตถุประสงค์                                                                                     |
| :-----: | :-------------------- | :---------: | :-------------: | :------------------------------------------------------------------------------------------------------------- |
|  **1**  | **`SHARED_DATA`**     |   ~1.4 TB   |    **ExFAT**    | เก็บไฟล์งานทั่วไป, โปรแกรม Portable, ISO Images สำหรับ Ventoy และข้อมูลที่ใช้แชร์ข้าม OS (Windows/macOS/Linux) |
|  **2**  | **`VM_LABS`**         |   400 GB    |    **NTFS**     | เก็บไฟล์ดิสก์เสมือนของ VirtualBox (`.vdi`) / VMware (`.vmdk`) บน SSD เพื่อความเสถียรและประสิทธิภาพสูงสุด       |
|  **3**  | **`LINUX_OS`**        |   200 GB    | **Unallocated** | พื้นที่ว่าง (แถบสีดำ) สำรองไว้สำหรับการติดตั้ง Kali Linux แบบบูตตรง (Direct Boot)                              |

## 🛠️ STEP 1: การเตรียมหัวใจของระบบ (Ventoy Installation)
> ⚠️ **คำเตือนสำคัญ:** ขั้นตอนนี้จะล้างข้อมูลทั้งหมดใน SSD กรุณาสำรองข้อมูลที่สำคัญออกมาก่อนเริ่มดำเนินการ
1. **Download (ดาวน์โหลดโปรแกรม):**
   - ไปที่เว็บไซต์หลัก [ventoy.net](https://www.ventoy.net/)
   - ดาวน์โหลดไฟล์สำหรับ Windows (รูปแบบ `.zip`) และทำการแตกไฟล์ (Extract) ออกมา
2. **Launch (เปิดใช้งานโปรแกรม):**
   - เสียบ External SSD เข้ากับคอมพิวเตอร์
   - ดับเบิลคลิกเปิดไฟล์ `Ventoy2Disk.exe`
3. **Configure Space (ตั้งค่ากันพื้นที่ - *ขั้นตอนสำคัญที่สุด*):**
   - ไปที่เมนู **Option** (ตัวเลือก) ด้านบน > **Partition Configuration** (การกำหนดค่าพาร์ทิชัน)
   - ติ๊กถูก `✓` ที่ช่อง **Preserve some space at the end of the disk** (สำรองพื้นที่ว่างไว้ที่ส่วนท้ายของดิสก์)
   - ระบุตัวเลข **`600`** และเลือกหน่วยเป็น **`GB`** *(พื้นที่ส่วนนี้จะถูกจองไว้สำหรับลง Linux Direct Boot 200GB + VM Labs 400GB)*
   - กด **OK** (ตกลง)
4. **Secure Boot Support:**
   - ตรวจสอบว่ามีเครื่องหมายถูก `✓` หน้าหัวข้อ **Secure Boot Support** (ปล่อยไว้ตามค่าเริ่มต้น)
   - **เหตุผล:** ช่วยให้ Ventoy สามารถบูตผ่านคอมพิวเตอร์รุ่นใหม่ที่มีการเปิดใช้งานระบบรักษาความปลอดภัย Secure Boot
5. **Partition Style (ตั้งค่ารูปแบบพาร์ทิชัน - *ต้องเปลี่ยน*):**
   - ไปที่เมนู **Option** > **Partition Style**
   - เปลี่ยนจากค่าเริ่มต้น (MBR) ให้เป็น **`GPT`**
   - **เหตุผล:** รองรับดิสก์ความจุเกิน 2TB, รองรับระบบ UEFI 100%, ทำงานได้รวดเร็วและปลอดภัยกว่า
6. **Install (เริ่มติดตั้ง):**
   - ตรวจสอบช่อง **Device** ให้แน่ใจว่าเป็น External SSD ของคุณ
   - กดปุ่ม **Install** > ยืนยัน **Yes** จำนวน 2 ครั้ง เพื่อเริ่มล้างข้อมูลและติดตั้ง Ventoy
7. **Finish (เสร็จสิ้น):**
   - เมื่อเสร็จ 100% ให้ปิดโปรแกรม SSD จะมีพาร์ทิชันหลักขนาด ~1.4TB และมีพื้นที่ว่างเปล่า (Unallocated) ซ่อนอยู่ 600GB

## 🛠️ STEP 2: การแบ่งห้องสำหรับจัดเก็บข้อมูล (Disk Partitioning)
1. **Open Disk Management (เปิดตัวจัดการดิสก์):**
   - บน Windows คลิกขวาที่ปุ่ม **Start** > เลือก **Disk Management** (หรือกด `Win + X` > `K`)
2. **Shrink Volume (หดขนาดพื้นที่):**
   - คลิกขวาที่แถบพาร์ทิชันใหญ่ของ External SSD (ชื่อ `Ventoy`) > เลือก **Shrink Volume...**
   - ในช่อง **Enter the amount of space to shrink in MB** ให้พิมพ์: **`409600`** *(คิดเป็น 400 GB)*
   - กด **Shrink**
3. **Create `VM_LABS` (สร้างห้องสำหรับเครื่องจำลอง):**
   - จะเกิดพื้นที่ว่างสีดำ (Unallocated) ขนาด 400GB ให้คลิกขวา > **New Simple Volume...**
   - กด **Next** จนถึงหน้าตั้งค่า Format:
     - **File system:** **`NTFS`**
     - **Volume label:** **`VM_LABS`**
   - กด **Next** และ **Finish**
4. **Rename Main Drive (เปลี่ยนชื่อไดรฟ์หลัก):**
   - กลับมาที่พาร์ทิชันใหญ่ส่วนแรก (~1.4TB) คลิกขวา > **Properties**
   - เปลี่ยนชื่อ **Label** เป็น **`SHARED_DATA`** *(Format จะเป็น ExFAT ตามที่ Ventoy สร้างไว้)*

## 🛠️ STEP 3: ขั้นตอนการติดตั้ง Kali Linux ลงในพื้นที่ 200GB (ฉบับละเอียดพิเศษ)
1. **การเตรียมการและเข้าสู่หน้าติดตั้ง**
   - **Boot:** คัดลอกไฟล์ ISO ของ Kali Linux ไปไว้ในไดรฟ์ `SHARED_DATA` จากนั้นเสียบ SSD ไว้ แล้วสั่ง Restart คอมพิวเตอร์ ทันทีที่หน้าจอดับแล้วเริ่มติดใหม่ ให้กดปุ่ม Boot Menu รัวๆ (เช่น `F12` สำหรับ Dell/Lenovo, `F9` สำหรับ HP, `F11` สำหรับ MSI หรือ `ESC`/`F2` สำหรับ ASUS)
   - **Select Ventoy:** ในรายการ Boot Menu ให้เลือกชื่อ **Seagate One Touch SSD** (หากมีตัวเลือกคำว่า UEFI นำหน้า ให้เลือกตัวนั้น)
   - **Start Installer:** เมื่อหน้าจอ Ventoy สีฟ้าขึ้นมา ให้เลื่อนไปที่ไฟล์ Kali ISO แล้วกด Enter จากนั้นเลือกเมนู **Graphical Install**
2. **การตั้งค่าพื้นฐาน (Configuration)**
   - **Language & Location:** เลือก **English** สำหรับภาษาหลัก และ **Thailand** สำหรับตำแหน่งที่ตั้ง (Keyboard เลือก **American English**)
   - **Hostname:** กำหนดชื่อเครื่อง เช่น `archon` (ชื่อนี้จะแสดงใน Terminal ของคุณ)
   - **User & Password:**
     - **Full name:** ใส่ชื่อของคุณ
     - **Username:** ตั้งชื่อที่ใช้ Login (แนะนำให้ใช้ตัวพิมพ์เล็กทั้งหมด)
     - **Password:** ⚠️ **สำคัญมาก** กำหนดรหัสผ่านที่จำได้แม่นยำ เพราะต้องใช้สิทธิ์ `sudo` และการติดตั้งเครื่องมือ Security Tools ทุกครั้ง
3. **การจัดการพาร์ทิชัน (Partition Disks) - จุดอันตราย!**
   ขั้นตอนนี้คือการสั่งให้ Kali ติดตั้งลงในพื้นที่ว่าง 200GB Unallocated ที่เตรียมไว้:
   - **เลือกโหมด:** เลือก **`Guided - use the largest continuous free space`**
     - *เหตุผล:* ระบบจะข้ามพาร์ทิชัน Windows และ `SHARED_DATA` ของคุณไป แล้ววิ่งไปเลือกพื้นที่ว่าง 200GB (สีดำ) ท้ายดิสก์ให้อัตโนมัติ
   - **Scheme:** เลือก **`All files in one partition (recommended for new users)`** เพื่อความสะดวกในการจัดการระบบไฟล์
   - **หน้าสรุป:** ระบบจะแสดงพาร์ทิชันใหม่ที่สร้างขึ้นมา (โดยปกติเป็น `ext4` และ `Swap`)
     - ให้เลือก **`Finish partitioning and write changes to disk`**
     - เมื่อระบบถามยืนยัน *"Write the changes to disks?"* ให้ตอบ **`Yes`** (หากตอบ No ระบบจะไม่เริ่มลงจริง)
4. **การเลือกซอฟต์แวร์ (Software Selection)**
   - มีรายการเครื่องมือให้เลือก ให้คงค่าเริ่มต้นไว้ (ติ๊กถูกที่ **Xfce** และ **default -- recommended tools**)
   - *เหตุผล:* **Xfce** คือ Desktop Environment ที่เสถียร เบา และประหยัดทรัพยากรที่สุดสำหรับการทำงานสาย Offensive Security
   - กด **Continue** และรอการติดตั้งระบบ (ใช้เวลาประมาณ 10-20 นาที ขึ้นอยู่กับความเร็ว SSD)
5. **การติดตั้งตัวบูต (Install GRUB Boot Loader) - จุดชี้ชะตา!**
   ขั้นตอนนี้คือการติดตั้งโปรแกรมสำหรับเลือก OS ตอนเปิดเครื่อง:
   - เมื่อระบบถาม *"Install the GRUB boot loader to your primary drive?"* ให้ตอบ **`Yes`**
   - 🛑 **ข้อควรระวังสำคัญที่สุด:** หน้าต่างถัดมา **ห้ามเลือก** `Enter device manually` และ **ห้ามเลือก** ไดรฟ์ของ Windows (มักจะเป็น `/dev/sda`) เด็ดขาด!
   - **ให้เลือก:** บรรทัดที่เป็นชื่อ **Seagate One Touch SSD** ของคุณเท่านั้น (สังเกตยี่ห้อ SSD หรือพาร์ทิชันเช่น `/dev/sdb` หรือ `/dev/sdc`)
   - *เหตุผล:* เพื่อให้ Boot Loader อยู่ใน SSD ลูกนี้เท่านั้น เวลาถอด External SSD ออก คอมพิวเตอร์จะบูตเข้า Windows หลักได้ตามปกติเหมือนไม่มีอะไรเกิดขึ้น
6. **เสร็จสิ้นการติดตั้ง (Finish)**
   - เมื่อขึ้นหน้าต่าง **Installation is complete** ให้กด **Continue** เพื่อทำการ Restart เครื่อง
   - ดึงตัวติดตั้งออก และพร้อมเริ่มใช้งาน Kali Linux แบบ Direct Boot ได้ทันที
