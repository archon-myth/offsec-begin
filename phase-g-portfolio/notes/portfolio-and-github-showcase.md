## 📝 GitHub Profile Hygiene Standards
1. **Clean Code & Commits:** ใช้ Conventional Commits (`feat:`, `fix:`, `docs:`) สม่ำเสมอ
2. **README with Architecture Diagram:** ทุกโปรเจกต์ต้องมี README อธิบายปัญหา, วิธีแก้, Flowchart, และวิธีรัน
3. **No Hardcoded Secrets:** สแกน Git History ด้วย `trufflehog` หรือ `git-secrets` ก่อนปล่อยสู่สาธารณะเสมอ
